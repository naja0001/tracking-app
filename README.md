# Walking Tracker App

A mobile tracking application built with **React Native** that helps users monitor their daily walking activity, including steps and walking distance.

## About the Project

The Walking Tracker App was developed as a mobile application for tracking physical activity. The main purpose of the app is to give users a simple overview of how much they walk during the day.

The application focuses on:

- Tracking daily steps
- Tracking walking distance
- Displaying walking activity in a simple interface
- Giving users an overview of their activity

## Features

### Step Tracking
The app tracks the user's steps and displays the number of steps taken.

### Distance Tracking
Users can see how far they have walked based on their tracked activity.

### Activity Overview
The application presents the user's walking data in an easy-to-understand format.

### Mobile Application
The app is built specifically for mobile devices using React Native.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/walking-tracker.git
cd walking-tracker
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the application

```bash
npx expo start
```

You can then run the application using:

- Expo Go on a physical device
- Android Emulator
- iOS Simulator

## How It Works

The application collects walking activity from the user's device and uses the data to provide information about their daily activity.

The basic flow is:

```text
User walks
    ↓
Device collects activity data
    ↓
Application processes the data
    ↓
Steps & distance are displayed
```
